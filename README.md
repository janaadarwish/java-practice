# ☕ Java Practice

A collection of Java exercises and practice problems covering core programming concepts and object-oriented design.

## 📁 File Overview

### Utility / Algorithm Files
| File | Description |
|------|-------------|
| `CountOccurrences.java` | Counts occurrences of elements in a collection |
| `IsSorted.java` | Checks whether an array is sorted |
| `RemoveDuplicates.java` | Removes duplicate elements from an array |
| `Reverse.java` | Reverses an array or sequence |
| `Shuffle.java` | Randomly shuffles an array |
| `Sort.java` | Sorting algorithm implementation |
| `Sum.java` | Computes the sum of array elements |
| `Max.java` | Finds the maximum value using generics |

### Object-Oriented Design
| File | Description |
|------|-------------|
| `Octagon.java` | Models an octagon shape |
| `Rational.java` | Represents rational numbers with arithmetic operations |
| `GeometricObjectMax.java` | Finds the max among geometric objects |
| `ansComparableCircle.java` | Circle class implementing the `Comparable` interface |
| `Main.java` | Main entry point / driver class |

## 🧠 Topics Covered

- Arrays (sorting, searching, reversing, shuffling)
- Generics and `Comparable` interface
- Object-oriented programming (classes, inheritance, interfaces)
- Rational number arithmetic
- Geometric shape modeling
- Algorithmic problem solving

## 🚀 Getting Started

### Prerequisites
- Java JDK 8 or higher

### Running a File
```bash
javac FileName.java
java FileName
```

For example:
```bash
javac Sort.java
java Sort
```

## 📌 Notes

- Each file is a standalone Java program or class.
- The `Q#_#.java` files correspond to textbook or course exercises organized by chapter and question number.
